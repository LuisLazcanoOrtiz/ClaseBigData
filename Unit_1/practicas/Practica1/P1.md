# Práctica 1 – Trabajo colaborativo con GitHub

##  Objetivo

En esta práctica vamos a crear un repositorio en GitHub, trabajar con ramas y aplicar un flujo básico de colaboración similar a Git Flow.  
El objetivo es que todos participen y comprendan cómo se trabaja en equipo usando control de versiones.

---

##  Crear el repositorio

1. Entrar a https://github.com  
2. Crear un nuevo repositorio llamado **ClaseBigData**  
3. Activar la opción **Add a README file**  
4. Crear el repositorio  

El archivo `README.md` será el documento principal del proyecto.

---

##  Agregar a los integrantes

Dentro del repositorio:

1. Ir a **Settings**
2. Seleccionar **Collaborators**
3. Agregar a los compañeros usando su usuario de GitHub
4. Asignar permiso **Write**

Esto permitirá que todos puedan subir cambios al proyecto.

---

##  Clonar el repositorio

**Abrir la terminal y ejecutar:
**
```bash
git clone https://github.com/LuisLazcanoOrtiz/ClaseBigData.git
cd ClaseBigData
```
## 4️ Crear la rama de trabajo `unit1`
**No vamos a trabajar directamente sobre `main`.
**
```bash
git checkout -b unit1
git push -u origin unit1
```

## Crear la estructura de carpetas
**Asegurarse de estar en la rama correcta:
**
```bash
git checkout unit1
```
**Crear la siguiente estructura:
**Unit_1
│
├── practicas
│   └── practica_1.txt
│
├── investigaciones
│   └── investigacion_1.txt
│
└── practica_evaluatoria
    └── practica_evaluatoria.txt
```bash 
mkdir Unit_1
cd Unit_1

mkdir practicas
mkdir investigaciones
mkdir practica_evaluatoria

echo Practica 1 > practicas/practica_1.txt
echo Investigacion 1 > investigaciones/investigacion_1.txt
echo Practica Evaluatoria > practica_evaluatoria/practica_evaluatoria.txt

cd ..
```

## Subir los cambios usando una rama feature
```bash
git checkout -b feature/unit1-structure
```

## Agregar y confirmar cambios

```bash 
git add .
git commit -m "Se agrega estructura de carpetas de la Unidad 1"
git push -u origin feature/unit1-structure
```

**Despues** :
Ir a GitHub

Crear un Pull Request

Base: unit1

Compare: feature/unit1-structure

Hacer Merge

## Actualizar el repositorio (para los demás integrantes)

```bash
git checkout unit1
git fetch
git pull origin unit1
```
